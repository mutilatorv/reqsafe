# ReqSafe

Petit site statique de vérification SafePal / Solana.

## Fichiers
- `index.html` : interface
- `style.css` : mise en page
- `app.js` : détection du provider SafePal/Solana

## Important
Cette version ne crée, ne signe et n’envoie aucune transaction crypto. Elle sert uniquement à vérifier que la page est bien ouverte dans un environnement wallet compatible avant toute étape supplémentaire.

## Hébergement
Le projet peut être publié tel quel sur un hébergeur statique HTTPS (Netlify, Cloudflare Pages, Vercel, GitHub Pages, etc.).
